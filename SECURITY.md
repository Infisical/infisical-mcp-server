# Security Policy

## Reporting a vulnerability

**Please do not open a public GitHub issue for a security problem.**

Report it through Infisical's vulnerability disclosure policy at <https://infisical.com/vulnerability-disclosure>.

Please include what you found, where, how to reproduce it, what an attacker could achieve, and how you would like to be credited.

## Scope and safe harbour

The full scope of the program, along with our safe harbour and coordinated disclosure terms, is set out in the policy linked above.

## Supported versions

Security fixes ship in the latest release of `@infisical/mcp`. If you pin a version, upgrade promptly when a release fixes a security issue. The README explains how to [pin, verify and roll back](README.md#pinning-verifying-and-rolling-back) a release.

## General security contact

For compliance documentation, security questionnaires and similar requests, use [security@infisical.com](mailto:security@infisical.com). That address is not a vulnerability intake channel.
